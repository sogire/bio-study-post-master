# Scientific Skills Interactive Laboratory Suite

Welcome to the interactive lab guides supporting your [12-Week Bioinformatics Curriculum](../plan.md).

---

## How to Conduct These Labs

You do **not** need to write or run Python scripts. As a computational biologist and scientific investigator, your objective is to:
1. **Formulate the scientific inquiry**.
2. **Direct the agent to employ the right skills**.
3. **Analyze and interpret the biological data**.

Each module directory contains a dedicated `lab_guide.md` with:
- **Biological Background & Context**: What happens inside the cell/organism.
- **Copy-Paste Interaction Prompts**: Prompts you can give directly to the agent in chat.
- **Expected Scientific Outputs**: Key metrics and what they mean.
- **Critical Discussion Questions**: To deepen your biological intuition.

All completed exercise reports, scripts, and generated assets are stored in each module's `result_labs/` directory following the standardized conventions in [GUIDE.md](GUIDE.md).
